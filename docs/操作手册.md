# Mock Server 操作手册

> 面向日常使用（联调 / 测试）的任务速查手册。架构说明、规则语法全集见 [README.md](../README.md)。  
> 工程路径：`mock-server/`（零依赖，仅需 Node ≥ 16）。



---

## 1. 快速开始（本机 3 分钟）

```bash
cd mock-server
node server.js                      # 免密模式，默认端口 18080
# 或账密模式：
MOCK_ADMIN_USER=admin MOCK_ADMIN_PASS=admin123 PORT=18082 node server.js
```

| 地址                                 | 用途                  |
| ---------------------------------- | ------------------- |
| `http://127.0.0.1:18080/`          | 管理界面（三栏控制台）         |
| `http://127.0.0.1:18080/{模块}/{接口}` | 挡板调用入口（给被测系统指的上游地址） |

界面三栏：**左**=接口列表 → **中**=规则编排 → **右**=实时请求日志。改完规则点保存立即生效，不用重启。

## 2. 部署模式速查

| 模式        | 启动方式                                    | 谁能开控制台             | 能否生成分享链接                      |
| --------- | --------------------------------------- | ------------------ | ----------------------------- |
| 免密        | `node server.js`                        | 任何人                | ❌（403，除非配 `READONLY_PORT`）    |
| 免密 + 只读端口 | `READONLY_PORT=18081 node server.js`    | 任何人                | ✅ 分享链接落在只读端口，去掉 `?share=` 也只读 |
| 账密        | `MOCK_ADMIN_PASS=secret node server.js` | 需登录（用户名默认 `admin`） | ✅ 登录后即可生成，链接指向主端口             |
| 账密 + 只读端口 | 两者都设                                    | 需登录                | ✅（链接仍走主端口）                    |

**环境变量一览**（均为可选）：

| 变量                                             | 默认      | 说明                  |
| ---------------------------------------------- | ------- | ------------------- |
| `PORT` / `config.server.port`                  | `18080` | 主端口                 |
| `MOCK_ADMIN_USER`                              | `admin` | 部署管理员用户名            |
| `MOCK_ADMIN_PASS`                              | 空       | 设了即开启登录保护           |
| `READONLY_PORT` / `config.server.readonlyPort` | `0`（关）  | 只读隔离端口，专供分享链接       |
| `MOCK_DEFAULT_LANG` / `config.defaultLang`     | 中文      | 部署期默认语言（用户手选后以用户为准） |
| `MOCK_SEED`                                    | —       | 设 `1` 时灌入演示日志种子     |

> ⚠️ 变量名是 `MOCK_ADMIN_PASS`，写成 `ADMIN_PASSWORD` 不会生效（会静默变回免密）。  
> 启动横幅会打印当前登录模式：`控制台登录 : 已启用/未启用`，不用猜。

### 部署到测试服务器（一键脚本）

本机执行（`deploy.sh` 会自动 ssh 过去装好、开机自启、放行端口）：

```bash
cd mock-server
./deploy.sh root@<测试机IP> -r 18081          # 免密 + 只读端口 18081（推荐给测试同学）
```

| 结果 | 地址 |
| --- | --- |
| 你自己改规则 | `http://<测试机IP>:18080/`（免密，谁都能改——别发出去） |
| 发给测试同学的只读链接 | 界面右上 **分享图标** 生成，形如 `http://<测试机IP>:18081/?share=shr-xxxx` |

- 只读端口上：`/login` 被禁、写操作一律 403、链接里去掉 `?share=` 只会看到「需要有效的分享链接」。
- 防火墙要放行 **两个** 端口（脚本会用 firewalld 自动放行）；**主端口建议只对你/内网网段开放**，别把 `18080` 公开。
- 容器方式（宿主没 node）：`./deploy.sh root@<测试机IP> -m docker -r 18081`。
- 只读端口不能和主端口相同；`-r` 参数与 `READONLY_PORT` 环境变量等价。
- **更新已部署的版本**：参数与首次部署一致，同一条命令重跑即可（幂等；远端 `config.json` 会保留，规则不丢），详见 README 4.6。
- 顶栏「联系维护者」（✉）与「GitHub」都来自远端 `config.json` 的 `meta`：前者读 `contactEmail`，后者读 `repoUrl`（只在目标机上设邮箱，别提交进仓库；仓库地址是公开信息）。

  ```bash
  ssh <user>@<HOST_IP> 'cd <安装目录> && node -e "const fs=require(\"fs\"),c=JSON.parse(fs.readFileSync(\"config.json\",\"utf8\"));c.meta=Object.assign({contactLabel:\"维护者\"},c.meta,{contactEmail:\"you@example.com\"});fs.writeFileSync(\"config.json\",JSON.stringify(c,null,2));console.log(c.meta)"'
  ```

## 3. 接口与规则（日常主操作）

1. 左栏 **☰ → 新建分组 / 新建接口**，接口路径 = `/{模块}/{接口}`（如 `/demo/sample`）。
2. 中栏 **+ New rule** 添加规则，每条规则 = 匹配条件 + 响应：
   - **取值来源**：请求体 / URL 参数 / 请求头 / 原始文本；
   - **操作符**：包含、前缀、正则、属于、存在、数值比较等；
   - 支持数组通配（`items[*].code`）；多条规则**自上而下命中即停**，可拖拽调顺序；
   - 规则可整体停用/启用（开关）、可复制（复制这条规则）。
3. **兜底返回**：所有规则都不命中时返回的内容，必配。
4. **代理回源**：接口设置里填真实服务根地址，该接口未命中挡板行为时透传真实上游，适合"大部分真实、个别挡板"。
5. **脚本响应**：响应类型选脚本，可按请求数组逐项生成不同返回（语法见 README 第七章）。

## 4. 试打（不连被测系统先自证）

中栏右上 **试打一枪**：填请求体 → 发送 → 直接看命中了哪条规则和返回内容。  
联调前先试打，能区分"规则配错"和"被测系统没调对"。

## 5. 把被测系统指到挡板

- 被测系统的上游 base URL 改成 `http://<挡板机IP>:18080`（**结尾不要带 `/`**）。
- 顶栏 🔗 图标可复制完整调用地址（根地址 + 当前接口路径）。
- 本机联调示例：`http://127.0.0.1:18080/demo`。

## 6. 分享链接（只读视图，给同事看规则）

顶栏 **分享图标** → 弹窗内 **生成分享链接**：

- 每条链接左侧有 **复制图标**（悬停显示"复制链接"），点击即复制；右侧 **撤销** 可随时作废。
- 对方打开只能看规则、不能改；服务端同时兜底拒绝写请求。
- 免密 + 只读端口模式下，链接落在只读端口——**对方把 URL 上的 `?share=` 去掉也依然只读**，永远摸不到可编辑主端口。
- 链接失效（被撤销）时对方会看到"分享链接已失效"提示页，不会降级成可编辑视图。

| 事实   | 说明                                                     |
| ---- | ------------------------------------------------------ |
| 令牌存储 | `config.json` 的 `shareTokens`，上限 20 条                  |
| 令牌传递 | `Authorization: Bearer <token>` 或 URL `?share=<token>` |
| 撤销   | 弹窗内撤销，或 `DELETE /_admin/share?token=<token>`           |

## 7. 登录与用户管理

- **部署管理员**：`MOCK_ADMIN_USER` / `MOCK_ADMIN_PASS` 环境变量，优先级最高，可管理普通用户。
- **普通用户**：存 `config.json` 的 `users`（SHA-256 哈希，无明文）。登录后点头像 → **Users** 增删改。
- 两种账号可并存；只读分享链接不需要登录。
- 忘记部署口令：重启时换 `MOCK_ADMIN_PASS` 即可；改普通用户密码用界面，或 `tools/add-user.js <用户名> <密码>`。

## 8. 请求日志排查

右栏实时滚动每个命中请求：时间、路径、状态码、耗时、命中规则。

| 操作       | 入口                                     |
| -------- | -------------------------------------- |
| 只看当前接口   | 右栏第一个开关                                |
| 暂停自动刷新   | 右栏第二个开关                                |
| 清空       | 清空（清的是全部日志，命中计数不受影响）                   |
| 按接口过滤拉历史 | `GET /_admin/logs?apiId=<id>&limit=50` |

---

## 9. 导入 / 导出与迁移

- **导出**：顶栏「导出」得到 JSON（含接口、分组、规则）。
- **导入**：顶栏「导入」，冲突时可选：跳过冲突 / 覆盖本地 / 改名导入为副本（适合两份配置 diff）。
- **整机迁移**：拷走整个目录即可（`config.json` 就是全部状态），无需导出。

## 10. 服务器部署与运维

| 方式      | 命令                                                            | 说明                     |
| ------- | ------------------------------------------------------------- | ---------------------- |
| 一键脚本    | `MOCK_ADMIN_PASS=secret ./deploy.sh root@<HOST_IP>`           | 打包上传 + systemd/cron 拉起 |
| systemd | 参考 `mock-server.service`，`Environment=MOCK_ADMIN_PASS=...`    | 推荐，开机自启                |
| Docker  | `MOCK_ADMIN_PASS=... MOCK_PORT=18080 ./deploy.sh`（compose 模式） | 见 `docker-compose.yml` |
| 裸进程     | `nohup node server.js &` + `@reboot` cron                     | deploy.sh 默认兜底         |

运维要点：

- 日志：`mock-server.log`（脚本拉起）或 `journalctl -u mock-server`（systemd）。
- 防火墙：**放行只读端口、收住主端口**才能完整隔离（否则分享隔离形同虚设）。
- 改 `config.json` 后：界面 Reload config 或 `POST /_admin/reload`；服务还会监听文件变更自动重载（含 users）。
- 健康检查：`GET /_admin/health`。

## 11. 常见问题（FAQ）

| 现象               | 原因与处理                                |
| ---------------- | ------------------------------------ |
| 设了环境变量但还是免密      | 变量名写错（应为 `MOCK_ADMIN_PASS`）；看启动横幅确认  |
| 改了规则界面没变化        | 浏览器缓存，`Cmd+Shift+R` 强刷               |
| 对方打不开分享链接        | 只读端口未放行防火墙；或链接已被撤销                   |
| 免密模式分享按钮报 403    | 正常防护：未配 `READONLY_PORT` 时免密不允许生成分享   |
| 端口被占用            | `lsof -nP -iTCP:18080` 找进程；或换 `PORT` |
| 中文界面出现英文示例文案     | 旧版本前端缓存，强刷；`seed.*` 文案已随界面语言切换       |
| 本机 curl 本地端口 502 | 环境代理劫持，加 `--noproxy '*'`             |
| 脚本响应写错了拖垮服务      | 单请求异常被进程兜底捕获，服务不会挂；修正规则即可            |

| 接口               | 方法                  | 说明                |
